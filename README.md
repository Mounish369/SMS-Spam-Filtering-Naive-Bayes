## 1. Project Objective
The objective is to classify SMS messages into Spam
and Ham (legitimate) categories using Machine Learning.

## 2. Dataset
UCI SMS Spam Collection Dataset.

- Total messages: 5,574
- Ham messages: 4,827
- Spam messages: 747

## 3. Algorithm
Multinomial Naive Bayes classifier.

## 4. Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

## 5. Implementation
The project uses CountVectorizer for text feature extraction
and Multinomial Naive Bayes for classification.

Refer to the executed Jupyter Notebook for the actual
